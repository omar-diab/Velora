# VELORA Learning Log

This file tracks the developer's learning progress across all skills required to build VELORA. It is the source of truth for "what do I actually know" as distinct from PROCESS.md, which tracks "what are we building right now."

Status values:

- `NOT_STARTED` — not yet introduced.
- `LEARNING` — currently studying the concept.
- `PRACTICING` — actively exercising it in small, isolated examples.
- `VERIFIED` — demonstrated understanding through explanation, a coding/debugging exercise, or review (see PROCESS.md's Validation System). Watching a tutorial is never sufficient on its own.
- `APPLIED` — used correctly inside the actual VELORA codebase, and can be explained/reproduced without AI.

A skill should not be marked `VERIFIED` or `APPLIED` without a corresponding entry in a step's Verification section in PROCESS.md.
